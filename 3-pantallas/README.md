# Pantallas — ECOFIE

Se incluyen cinco prototipos vectoriales SVG:
1. `01-inicio.svg`: portada.
2. `02-menu.svg`: menú principal.
3. `03-decision.svg`: situación y alternativas.
4. `04-consecuencia.svg`: explicación del efecto de la elección.
5. `05-resultados.svg`: resumen y puntuación.

Los SVG se pueden abrir en navegador o importar a Figma, Canva o Inkscape. La consigna solicita PNG: exporta cada prototipo a PNG y guarda las imágenes en esta carpeta.

No se ha añadido un enlace externo de Figma/Canva porque todavía no se ha creado un archivo en esas plataformas.
