# Diagramas UML — ECOFIE

Los archivos `.puml` son fuentes editables de PlantUML. Para generar PNG, abre cada archivo en un editor compatible o en https://www.plantuml.com/plantuml/ y exporta la imagen.

- `casos-de-uso.puml`: interacción del jugador con el juego.
- `diagrama-clases.puml`: clases principales y relaciones.
- `diagrama-secuencia.puml`: proceso de seleccionar una decisión y mostrar su consecuencia.

Después de exportar, guarda también las imágenes como `casos-de-uso.png`, `diagrama-clases.png` y `diagrama-secuencia.png` en esta carpeta.
